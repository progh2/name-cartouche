# 돌에 새긴 이름 · Carved in Stone

한글 이름을 **로마자 · 그리스어 · 이집트 상형문자 카르투슈 · 룬 · 페니키아 · 쐐기(우가리트) · 오검**으로 음역(소리 옮김)하는 작은 정적 사이트입니다. 번역이 아니라 발음을 옮깁니다.

- 순수 HTML/CSS/JS, 빌드 없음. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.
- 변환 로직: `convert.js` (브라우저·Node 공용). 테스트: `node test/convert.test.js`
- 3D 무대(three.js): 문자마다 재료가 바뀌는 판(석회암·파피루스·화강암 룬스톤·점토판·오검 기둥·대리석)에 글자를 한 자씩 새겨요. 첫 변환 때만 `vendor/three.min.js`(필요한 부분만 묶은 r170)를 불러오고, 그 전엔 정지 미리보기(`assets/stage-preview.webp`)를 보여 줘요. 움직임 줄이기 설정이나 WebGL이 없으면 같은 재료의 2D 판으로 보여 줘요(`?mode=2d`로도 확인 가능).
- 상형 탭: 카르투슈 두 개 — 왼쪽 즉위명(랜덤 칭호, ‘다시 뽑기’), 오른쪽 탄생명(내 이름).
- 기능: 문자 탭, 음절 표, SVG 카르투슈, PNG 저장, 텍스트 복사, 인스타 피드(1080×1350)·스토리(1080×1920) 카드(재료 질감 위 음각 합성) 미리보기
- 마지막으로 변환한 이름은 이 브라우저에 저장돼 다음 방문 때 다시 보여 줍니다 (우선순위: `?n=` > 저장된 이름 > 홍길동).
- 카르투슈는 파라오의 두 카르투슈 이름(즉위명 prenomen · 탄생명 nomen) 중 **탄생명**으로 표시합니다. 예: 람세스 2세 = 우세르마아트레(즉위명) / 람세스(탄생명).
- 주소에 `?n=홍길동`을 붙이면 바로 변환됩니다.

## 표기 규칙 (간단판)
- 로마자: 개정 로마자 기본값, 동화·연음 규칙 없음. 첫 음절 = 성 (공백을 넣으면 그대로 나눔). 예: 홍길동 → Hong Gildong
- 그리스어: g Γκ, k Κ, h Χ, b Μπ, d Ντ, j Τζ, ch Τσ, s Σ(끝 ς), m μ, n ν, r ρ(첫소리), l λ(받침), p π, t τ, 받침 ng γκ / a α, eo·o ο, u ου, i ι, e·ae ε, eu ι, y- → γι-, w- → ου-. 여러 음절 단어의 마지막 음절 모음에 강세. 예: Χογκ Γκιλντόγκ
- 상형문자: 단자음 기호 사용. eo·o·u → 𓅱, e·ae·eu·i → 𓇋, y- → 𓇌+모음, w-/oe/ui → 𓅱+모음, 받침 ng → 𓈖𓎼. 예: 𓉔𓅱𓈖𓎼 𓎼𓇋𓂋𓂧𓅱𓈖𓎼

- 룬(고대 푸사르크)·페니키아·우가리트 쐐기 알파벳·오검: 기본 모음(a e i o u)+반모음(y/w)으로 나눈 **소리 근사**. 페니키아는 모음을 𐤀/𐤉/𐤅로 근사, 오른쪽→왼쪽. 오검은 p가 없어 b(ᚁ)로, 앞뒤 깃표 ᚛ ᚜.

질감: `assets/tex/*.webp`는 상자에서 절차적으로 만든 색·노멀 맵(재료당 2장).

폰트: Google Fonts (Noto Sans KR, Noto Serif KR, Noto Serif, Noto Sans Egyptian Hieroglyphs/Runic/Phoenician/Ugaritic/Ogham, SIL OFL).
