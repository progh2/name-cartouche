# 이름 카르투슈

한글 이름을 **로마자 · 그리스어 · 이집트 상형문자 카르투슈 · 룬 · 페니키아 · 쐐기(우가리트) · 오검**으로 음역(소리 옮김)하는 작은 정적 사이트입니다. 번역이 아니라 발음을 옮깁니다.

- 순수 HTML/CSS/JS, 빌드 없음. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.
- 변환 로직: `convert.js` (브라우저·Node 공용). 테스트: `node test/convert.test.js`
- 기능: 문자 탭, 음절 표, SVG 카르투슈, PNG 저장, 텍스트 복사, 인스타 피드(1080×1350)·스토리(1080×1920) 카드 미리보기
- 주소에 `?n=함기훈`을 붙이면 바로 변환됩니다.

## 표기 규칙 (간단판)
- 로마자: 개정 로마자 기본값, 동화·연음 규칙 없음. 첫 음절 = 성 (공백을 넣으면 그대로 나눔). 예: 함기훈 → Ham Gihun
- 그리스어: g Γκ, k Κ, h Χ, b Μπ, d Ντ, j Τζ, ch Τσ, s Σ(끝 ς), m μ, n ν, r ρ(첫소리), l λ(받침), p π, t τ, 받침 ng γκ / a α, eo·o ο, u ου, i ι, e·ae ε, eu ι, y- → γι-, w- → ου-. 여러 음절 단어의 마지막 음절 모음에 강세. 예: Χαμ Γκιχούν
- 상형문자: 단자음 기호 사용. eo·o·u → 𓅱, e·ae·eu·i → 𓇋, y- → 𓇌+모음, w-/oe/ui → 𓅱+모음, 받침 ng → 𓈖𓎼. 예: 𓉔𓄿𓅓 𓎼𓇋𓉔𓅱𓈖

- 룬(고대 푸사르크)·페니키아·우가리트 쐐기 알파벳·오검: 기본 모음(a e i o u)+반모음(y/w)으로 나눈 **소리 근사**. 페니키아는 모음을 𐤀/𐤉/𐤅로 근사, 오른쪽→왼쪽. 오검은 p가 없어 b(ᚁ)로, 앞뒤 깃표 ᚛ ᚜.
